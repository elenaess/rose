# Sakura & Launcher estelar

Dois APKs independentes. Sakura 0.4.3 mantém o tema rosa e Termux. Launcher 1.0.1 tem tema navy/ciano, usa exclusivamente o papel de parede do sistema, desktop clássico, gaveta alfabética, animações de 90 ms e widgets nativos. Não contém integração Termux nem acesso às notificações. Ambos usam a API LauncherApps e alternativas para iniciar os apps instalados.

[Baixar em Actions](https://github.com/elenaess/rose/actions).
